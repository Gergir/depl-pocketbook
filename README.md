# 📚 Słownik niemiecko-polski depl.pl na PocketBooki
Najlepszy darmowy słownik niemiecko-polski oparty na bazie **depl.pl**:
- **Natywny format**: przygotowany specjalnie na **czytniki PocketBook** (w formacie `.dic`).
- **Ponad 71 000 haseł**: Szeroka baza słownictwa, od podstaw po zwroty specjalistyczne.
- **Pełna gramatyka**: rodzajniki, liczby mnogie, oznaczenia części mowy
- **Pomoc w trudnych formach**: Formy odmienione (np. gesungen) mają własne wpisy, które informują, od jakiego czasownika pochodzą
- **Przykłady i idiomy**: Słownik nie tylko tłumaczy słowo, ale pokazuje je w zdaniach. Dowiesz się, jak np. używając singen powiedzieć „śpiewać z nut” lub „imbryk śpiewa na kuchence”


## 💼 Jak pobrać?
Kliknij [TUTAJ](https://github.com/Gergir/depl-pocketbook/releases/download/v.1.1/niem_pol.dic) aby pobrać najnowszą wersję słownika lub użyj zakładki 'releases'.

## 👓 Jak zainstalować?

1. **Podłącz czytnik** do komputera kablem USB.
2. **Skopiuj pobrany plik** do folderu `system/resources/dictionaries` na czytniku.
![Gdzie wkleić słownik](img/slownik_instrukcja.jpg)  
(Jeśli nie widzisz folderu "system", możesz wpisać ścieżkę ręczkie w polu wyszukiwarki, tak jak na zdjęciu powyżej).
3. **Odłącz czytnik.** Gotowe! Słownik będzie dostępny na liście podczas czytania książki.
